# Flujos de usuario

## Flujo 1 — Revisar prioridades

Dashboard → filtrar vencidos/próximos → abrir informe → revisar responsable → actualizar estado/observación.

## Flujo 2 — Crear informe

Proyectos → detalle del proyecto → Nuevo informe → tipo → período → contactos → guardar → detalle de informe.

## Flujo 3 — Seguimiento de ciclo de vida

Pendientes Evidencias → Informe en Elaboración → Entregado a Of. Proyectos → Enviado.

Cada transición debe registrar fecha, actor y comentario cuando corresponda.

## Flujo 4 — Configurar alerta

Proyecto → Alertas → Nueva alerta → frecuencia/días → hora → destinatarios → activar → confirmar.

## Flujo 5 — Atender alerta

Notificación → abrir informe/proyecto → identificar acción → actualizar seguimiento → registrar resultado.

## Flujo 6 — Consulta ejecutiva

Dashboard → proyecto → detalle → indicadores → lista de informes → abrir excepciones.
