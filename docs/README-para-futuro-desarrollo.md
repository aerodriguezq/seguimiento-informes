# Ruta de trabajo recomendada

## Etapa 1 — Diseño

Crear en Figma los 6 mockups P0 y un design system mínimo.

## Etapa 2 — Contrato de datos

Validar con negocio el modelo relacional, catálogos y reglas de fecha/período.

## Etapa 3 — Backend

Implementar entidades, autenticación, autorización, CRUD e historial.

## Etapa 4 — Frontend

Construir navegación, Dashboard, Proyectos, Informes y Alertas.

## Etapa 5 — Automatización

Agregar scheduler, evaluación de reglas, notificaciones y reintentos.

## Etapa 6 — QA

Pruebas unitarias, integración, permisos, datos inconsistentes, alertas y accesibilidad.
