# Inventario de pantallas

| ID | Pantalla | Objetivo | Elementos |
|---|---|---|---|
| M01 | Dashboard | Priorizar | KPIs, vencidos, próximos, alertas, proyectos |
| M02 | Informes | Buscar/filtrar | Tabla, filtros, acciones |
| M03 | Nuevo Informe | Registrar | Formulario guiado |
| M04 | Detalle de Informe | Gestionar | Estado, timeline, contactos, observaciones |
| M05 | Proyectos | Navegar | Tabla/cards, cumplimiento |
| M06 | Detalle de Proyecto | Configurar + seguir | Tipos, alertas, informes, KPIs |
| M07 | Alertas | Administrar automatización | Reglas, frecuencia, destinatarios |
| M08 | Listas | Administrar catálogos | CRUD controlado |
| M09 | Notificaciones | Atender excepciones | Feed, filtros, acciones |

## Prioridad

P0 = indispensable para MVP.
P1 = importante después del core.
P2 = mejora/optimización.
