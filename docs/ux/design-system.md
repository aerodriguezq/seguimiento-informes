# Design system inicial

## Layout

- Grid principal de 12 columnas.
- Sidebar persistente en desktop.
- Contenido máximo amplio para tablas.
- Espaciado consistente basado en múltiplos de 4/8 px.

## Componentes

- Button
- Input
- Select
- Checkbox
- Multi-select
- Date picker
- Month-year picker
- Badge
- Status pill
- KPI card
- Data table
- Empty state
- Skeleton
- Toast
- Modal
- Drawer
- Timeline
- Notification item

## Estados

Todo componente interactivo debe definir: default, hover, focus, disabled, error y loading.

## Accesibilidad

- No depender únicamente del color.
- Contraste suficiente.
- Foco visible.
- Etiquetas claras.
- Navegación por teclado.
